# Error OS — Credits / Ghi nhận

Error OS ("ErrorOS-Hyper") là bản fork của **BugOS-Hyper** của KaoriTV / trkai,
và chịu ảnh hưởng cấu trúc từ **nothingsvn_xiaomi-toolbuild** (NothingSVN Toolbuild).
Cả hai dự án nguồn phát hành theo GPL (xem LICENSE). File build pipeline đã
được rebrand/sửa lại cho ROM Xiaomi China HyperOS OS4.0.2.0.XOLCNXM (Android 17, thiết bị `onyx`).

Credits chi tiết:

- **BugOS-Hyper** — https://github.com/trkai/BugOS-Hyper — pipeline gốc (payload/new.dat.br/super.img unpack, mod, repackEROFS, lpmake)
- **nothingsvn_xiaomi-toolbuild** — https://github.com/zuri1503/nothingsvn_xiaomi-toolbuild — bản fork song song, tham chiếu thiết kế overlay
- **ProjectZK / PROJECTZK** — bộ overlay Tiếng Việt cho app Xiaomi (chia sẻ lại với tên ErrorOS.Multi.*)
- **@MMETMAmods** — hướng dẫn vá miui-services.jar cho Android 17 (FCM fix)
- **SukiSU Ultra** — root LKM (https://github.com/ShirkNeko/SukiSU-Ultra)
- **KernelSU Next** — ksud host tool (https://github.com/KernelSU-Next/KernelSU)
- **MiuiX / Xiaomi** — firmware gốc Xiaomi (thuộc quyền Xiaomi Corporation)

Error OS **không phải sản phẩm chính thức** của Nothing, Xiaomi, hay Google.
